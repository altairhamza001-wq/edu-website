О проекте

Учебный проект для семинара по облачным технологиям.

Как устроен конвейер

  1. Студент делает git push в ветку main.
  2. GitHub Actions запускает job lint — проверку HTML через HTMLHint.
  3. Если проверка прошла, запускается job deploy.
  4. Файлы публикуются в ветку gh-pages, откуда их раздает GitHub Pages.
